### Featured projects

- **[hdvi-slam](https://github.com/halhalli-s/hdvi-slam)** — Real-time handheld dense visual-inertial SLAM (RGBD + IMU) on ROS 2, built from the camera driver up, with a GTSAM factor-graph backend and loop closure. ~1–2 cm position accuracy on closed-loop room scans.
- **[sfc_planner](https://github.com/halhalli-s/sfc_planner)** — Safe Flight Corridor planner for quadrotors using ADMM and IRIS, deployed on a real drone.
- **[dimscan](https://github.com/halhalli-s/dimscan)** — RGB-D perception system that measures irregular/deformable objects and predicts shipping-box dimensions from trusted 3D geometry.
- **[Pick-Place-PincherX100](https://github.com/halhalli-s/Pick-Place-PincherX100)** — Pick-and-place manipulation on a PincherX100 arm.
- **[Kinodynamic-Path-Planning](https://github.com/halhalli-s/Kinodynamic-Path-Planning)** — Kinodynamic motion planning respecting velocity and acceleration constraints.
